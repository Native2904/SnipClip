Связывание скриншотов со StickySnips

Скриншот и соответствующая заметка должны быть узнаваемы как связанные, без необходимости вводить имя вручную. Перетаскивание файла прямо на другой отдельный файл не поддерживается ни TC, ни Windows — целью перетаскивания всегда является папка. Поэтому связь образуется просто тем, что оба файла лежат в одной и той же подпапке:

StickySnips\tcmd\Lister\
    заметка.snip
    скриншот.bmp

Именно имя папки несёт настоящий смысл — у StickySnips иначе нет свободно выбираемого имени, только автоматическое превью из первых символов содержимого.

Самостоятельное закрепление изображений

Скриншот можно перетащить прямо из ! Screenshots в обычную, одноуровневую категорию (StickySnips\Картинки\) вообще без заметки — точно так же, как и текст. Хранить несколько изображений вместе таким образом — это просто обычная категория с несколькими записями. Глубина пути определяет, какой случай перед нами: один уровень = самостоятельное закрепление, два уровня = связь.

Поведение при удалении

Независимо от того, какая сторона связи удаляется, разрывается только сама связь — другой элемент остаётся полностью нетронутым. Удалённое изображение возвращается в ! Screenshots; удалённая заметка лишь разрывает связь, изображение остаётся. Та же логика, что и у истории↔StickySnip: удаляете один — другой (существующий независимо) остаётся нетронутым. Это не относится к самостоятельно закреплённым изображениям (один уровень) — там происходит настоящее удаление, поскольку там нет второй стороны, которую нужно было бы сохранить.

Видимость в папке скриншотов

Внутри вложенной папки StickySnip оба файла лежат рядом, видимые глазу. А вот в самой ! Screenshots находятся только изображения, без видимой связи с заметкой. Столбец Verknuepft показывает там имя связанной заметки (пусто = не связано) — тот же механизм пользовательских столбцов, что уже используется для существующих (Edited/Diff/Source/Age).

Лимит хранения

Два независимых лимита, поскольку размер изображений колеблется гораздо сильнее, чем у текста:

[image_capture]
max_screenshots=50
max_total_size_mb=200

Какой лимит сработает первым, тот и удаляет самый старый скриншот.

Значки

Связанные записи получают собственный значок в виде звена цепи вместо значка исходного приложения — "это связано" полезнее с первого взгляда, чем "это пришло из какой программы". Несвязанные записи вместо этого показывают настоящий значок программы-источника (извлечённый из её .exe), либо — если источник неизвестен или программа больше не существует — запасной значок, по умолчанию встроенный плавающий глаз, который можно свободно заменить своим .ico через FallbackSourceIcon=.

Порядок выбора значка: связано → настоящий значок программы-источника → запасной значок → значок TC по умолчанию.
