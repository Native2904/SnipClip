# Собственная тема Basic — как мы пришли к этому решению

У каждого из наших плагинов TC есть своя система тем (тёмная/светлая, несколько цветовых палитр). Вопрос был: должна ли тема "Basic" по умолчанию выглядеть одинаково во всех плагинах, или у каждого плагина должна быть своя?

Мы намеренно выбрали второй вариант. Когда несколько наших плагинов открыты одновременно — SnipClip, RecentTab, и другие в будущем — должно быть сразу понятно, какое окно к какому плагину относится, не читая заголовок окна. Общая тема по умолчанию свела бы этот эффект узнаваемости на нет.

Тема Basic в SnipClip называется **Alien Blood** — тёмно-зелёный фон, ядовито светящиеся акценты, взято из общедоступной палитры Gogh (не придумано нами). У RecentTab своя оранжево-тёмная схема. Обе намеренно различаются.

Три общие темы (Gruvbox, Everforest, Solarized) это не затрагивает — они выглядят одинаково во всех наших плагинах, так как это фиксированные, внешне определённые палитры, а не собственный фирменный дизайн.

## Осознанный пробел

У Alien Blood пока нет официального светлого варианта — палитра Gogh определяет только тёмную версию. Вместо того чтобы придумывать светлый вариант, который на самом деле не принадлежит палитре, `Mode=light` для Basic просто использует те же тёмные значения. Кому действительно нужен светлый вид Basic, может использовать `Name=custom` с собственно выбранными цветами.

## Настройка

```ini
[Theme]
Name=basic
Mode=dark
```
