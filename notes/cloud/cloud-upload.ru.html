Настройка облачной загрузки (ImgBB и Pastebin)

Кнопка «Загрузить» в диалоге Alt+Enter отправляет скриншот на ImgBB или текстовую запись (история, StickySnip, Textbaustein) на Pastebin и сразу записывает полученную ссылку в буфер обмена. Обе функции полностью отключены по умолчанию — ничего не покидает этот компьютер, пока вы явно это не настроите.

Главный переключатель

Один переключатель решает, возможна ли загрузка вообще, независимо от отдельных сервисов:

[cloud_upload]
Enabled=0

Сначала установите 1, только тогда начнут действовать настройки отдельных сервисов ниже. Сама кнопка остаётся полностью скрытой в диалоге, пока Enabled=0 или отсутствует соответствующий API-ключ — она никогда не появляется просто для того, чтобы потом не сработать.

Настройка ImgBB

Получите бесплатный ключ на api.imgbb.com, внесите его в ini-файл:

[cloud_upload_imgbb]
ApiKey=ВАШ_КЛЮЧ_IMGBB
ExpirationSec=0

ExpirationSec=0 (по умолчанию) означает, что изображения остаются онлайн постоянно. Значение от 60 до 15552000 (в секундах) вместо этого автоматически удаляет их по истечении указанного времени.

Настройка Pastebin

Здесь есть два разных ключа, которые легко перепутать:

  • Dev-ключ — ваш личный, постоянный API-ключ. Находится на pastebin.com/api (в залогиненном состоянии), в блоке «Your Unique Developer API Key». Требуется при каждом запросе.
  • User-ключ — подтверждает, что paste принадлежит вашему залогиненному аккаунту (приватные paste, собственная история paste, преимущества Power Member). Без него paste публикуется от имени гостя — тоже работает, но без этих преимуществ.

User-ключ получают один раз, через запрос входа (login). Согласно документации самого Pastebin, он не истекает, пока не будет создан новый — это не повторяющийся шаг. Выполните один раз в PowerShell:

$response = Invoke-RestMethod -Uri "https://pastebin.com/api/api_login.php" -Method Post -Body @{
    api_dev_key = "ВАШ_DEV_КЛЮЧ"
    api_user_name = "ВАШЕ_ИМЯ_ПОЛЬЗОВАТЕЛЯ"
    api_user_password = "ВАШ_ПАРОЛЬ"
}
$response

Последняя строка, $response, важна — без неё PowerShell только сохраняет результат, но не показывает его. Выведенное значение — это ваш user-ключ, вносится в ini-файл:

[cloud_upload_pastebin]
ApiKey=ВАШ_DEV_КЛЮЧ
UserKey=РЕЗУЛЬТАТ_СВЕРХУ
Private=1
ExpireDate=N
Имя пользователя и пароль нигде не сохраняются при этом одноразовом запросе — ни в плагине, ни в каком-либо лог-файле. Они используются только в момент входа. Тем не менее, не копируйте потом случайно историю PowerShell куда-либо ещё.

Private= определяет видимость новых paste: 0=публичный, 1=unlisted (по умолчанию), 2=приватный. ExpireDate= по умолчанию N (никогда) — либо собственные коды Pastebin: 10M/1H/1D/1W/2W/1M/6M/1Y.

Кнопка в диалоге Alt+Enter

Как только оба условия выполнены (главный переключатель включён, соответствующий ключ задан), рядом с «OK» появляется «Загрузить». При открытии диалога в фоне сразу запускается короткая проверка соединения (не настоящая загрузка, а просто проверка доступности):

  • Проверка соединения… — проверка выполняется, кнопка ещё неактивна
  • Соединение установлено — кнопка активна, нажатие запускает настоящую загрузку
  • Недоступно — кнопка остаётся неактивной, никакой попытки загрузки, которая всё равно провалилась бы
  • Загрузка… — загрузка выполняется, диалог при этом не блокируется
  • Загружено, ссылка скопирована: … — готово, ссылка уже в буфере обмена, дополнительный клик не нужен
  • Ошибка: … — с указанием причины, кнопка снова доступна для повторной попытки

Замечание по безопасности

Все ключи хранятся в открытом виде в SnipClip.ini — как и любая другая настройка, которую сохраняет плагин. Отдельного зашифрованного хранилища для них нет. Если вы передаёте, делаете резервную копию или синхронизируете этот ini-файл, ключи передаются вместе с ним.
