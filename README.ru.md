# SnipClip

Плагин для Total Commander, превращающий буфер обмена в доступный для поиска, постоянный каталог. Не отдельная программа, без значка в трее, без собственного постоянно открытого окна — SnipClip полностью живёт внутри TC, как виртуальная панель под `\SnipClip`.

## Что умеет

Вы копируете как обычно — Ctrl+C, из любой программы. SnipClip перехватывает это в фоне (ClipWatch, невидимое окно, зарегистрированное в Windows для отслеживания изменений буфера обмена, без опроса) и помещает текст в панель `\SnipClip` как виртуальный файл.

**Пароли остаются в стороне.** Когда приложение намеренно копирует что-то, что не должно отслеживаться — Bitwarden, KeePassXC, 1Password, режим инкогнито Chrome — оно помечает это официальным сигналом Windows. SnipClip уважает это и оставляет такие копии полностью нетронутыми. Честная оговорка: это добровольная просьба, а не принудительная блокировка — некоторые источники просто не устанавливают этот сигнал. Тот, кто всё же хочет перехватывать всё для собственного тестирования, может отключить это.

**История в принципе неизменяема** — но теперь не совсем без выхода. Изначально только `! Verlauf leeren` (очистить всё сразу) могло что-то удалить. Теперь, если туда попало что-то неправильное, можно удалить и отдельную запись — под защитой собственного дополнительного подтверждения поверх обычного запроса TC на удаление. Кто предпочитает прежнее строгое правило, может снова его включить.

**Редактирование возможно, но не оригинала.** F3 открывает сниппет в собственном Lister-плагине SnipClip. Ctrl+E переключает в режим редактирования (фон становится светлым), вы исправляете, Ctrl+S записывает прямо обратно в буфер обмена. Сама строка истории остаётся неизменной, вы лишь видите отметку о том, было ли и насколько сильно последнее редактирование.

**Важное вы закрепляете.** F5 или перетаскивание в категорию под `! StickySnips` — категории создаются через F7. Закреплённые сниппеты сохраняются, даже когда остальная история давно уже вытеснена.

**Объединение нескольких фрагментов в одно целое** перед использованием — фрагменты кода или текста, которые вы копируете один за другим под одним и тем же введённым именем в `! Textbaustein\Entwurf`, там добавляются, а не заменяются. Собрали всё нужное? Переименование через F6 из `Entwurf\` окончательно фиксирует результат. Подробности о том, почему добавление работает только по одному: см. [заметку о Textbaustein](notes/textbaustein/textbaustein.ru.html).

**Если вы копируете файл вместо текста**, SnipClip по умолчанию это игнорирует. Включив разрешение путей, вы получите путь к файлу в виде текста, собранного под `! Pfade`, полностью отдельно от основной истории.

**Скриншоты попадают в `! Screenshots`** — но только от программ, которые вы явно разрешили (`[image_capture_sources]` в ini, по принципу белого списка, как и разрешение путей). Например, если FastStone Capture кладёт изображение в буфер обмена после закрытия окна захвата, оно автоматически сохраняется как `.bmp`. Два независимых лимита хранения (`max_screenshots`, `max_total_size_mb`) не дают коллекции расти бесконтрольно — какой лимит сработает первым, тот и удаляет самый старый скриншот.

**Скриншоты можно закреплять** — либо самостоятельно (как текст: F5/перетаскивание из `! Screenshots` в обычную категорию StickySnips), либо связав с существующей заметкой, поместив оба файла в одну и ту же подпапку. Связанные записи показывают в `! Screenshots` отдельный столбец ("Verknuepft") с именем связанной заметки. Удаление любой стороны связи разрывает только саму связь — другой элемент остаётся полностью нетронутым. Подробности и почему решено именно так: см. [заметку о связывании](notes/screenshot-linking/screenshot-linking.ru.html).

**Каждая запись автоматически показывает значок своего исходного приложения** перед именем (извлечённый из самого `.exe`) — связанные записи вместо этого получают собственный символ звена цепи. Если источник неизвестен или тот `.exe` больше не существует, включается запасной значок (встроенный, либо свой `.ico` через `FallbackSourceIcon=`).

**Новые сниппеты появляются сразу**, без ручного Ctrl+R — как только вы хоть раз взаимодействовали с панелью (например, Alt+Enter), вид автоматически обновляется после каждого нового захвата.

Alt+Enter на отдельной записи показывает источник, категорию (для закреплённых сниппетов), время (абсолютное и относительное), статус редактирования и полное содержимое. Alt+Enter на одной из специальных строк показывает вместо этого общий обзор — время работы, статистику сессии, рейтинг источников, количество StickySnips, статистику редактирования, реальное использование диска.

## Подробности

### Структура панели: `! menu`

Все командные строки (`! ClipWatch pausieren`, `! Verlauf leeren`, `! StickySnips`, `! Pfade`, `! Textbaustein`, `! Kommentare`, `! Screenshots`) по умолчанию собраны под одной строкой: `! menu`. Это делает корень аккуратным — только ваши реальные сниппеты видны сразу.

```ini
[menu]
RootButtons=
```

Если вы предпочитаете, чтобы определённые команды были прямо в корне (например, потому что вы часто заходите в StickySnips), укажите их ключи через запятую: `RootButtons=Sticky,Path`. Доступные ключи: `Pause`, `Clear`, `Sticky`, `Path`, `Textbaustein`, `Comments`.

У каждой специальной строки свой небольшой значок (вместо стандартного символа файла/папки TC) — так их проще различать с первого взгляда, особенно когда несколько строк стоят рядом в `! menu`.

### `[history]` — основные настройки истории

- **`max_entries`** (по умолчанию 100) — максимум записей одновременно, самая старая автоматически удаляется
- **`name_preview_length`** (по умолчанию 20) — символы для имени в панели
- **`persist_history`** (по умолчанию 1) — сохраняется ли после перезапуска TC
- **`dedup_consecutive`** (по умолчанию 1) — две одинаковые копии подряд создают только одну запись
- **`AllowSingleDelete`** (по умолчанию 1) — можно ли вообще удалять отдельные записи

### `[Theme]` — внешний вид

Собственная тема "Basic" ("Alien Blood") как отличительная черта. Для согласованности с другими плагинами: `Name=gruvbox|everforest|solarized`, каждая с `Mode=dark|light`. `NoColors=1` в `[Settings]` полностью отключает любую тему.

**`FontBrightness=`/`BackgroundBrightness=`** (от -3 до +3, по умолчанию 0) — тонкая настройка яркости через фиксированные, проверенные шаги. Почему именно семь ступеней и почему шрифт/фон реагируют с разной силой: см. [заметку о яркости](notes/basic-theme/basic-theme.ru.html). Если комбинация даёт слишком низкий контраст, автоматически применяется безопасное значение с предупреждением в окне Alt+Enter.

**`TimeBasedMode=`** (по умолчанию 0) — если включено, текущий час определяет светлый/тёмный режим вместо `Mode=` (`LightStartHour=`/`DarkStartHour=`, по умолчанию 6-18 светлый). Действует сразу, без перезапуска. Влияет только на основные диалоги (Properties/Übersicht) — у Lister и маски комментариев Textbaustein свой независимый переключатель Ctrl+E, на который это не влияет.

### `[lister]` — редактор

Намеренно использует другую тему, чем остальной плагин (тёмная для чтения, светлая для редактирования): `gruvbox`, `everforest` или `solarized`. Почему сохранение здесь работает без ошибки загрузки TC: см. [заметку об AutoReUpload](notes/autoreupload/autoreupload.ru.html).

**`MonoFont=`/`MonoFontName=`** — собственный моноширинный шрифт вместо Consolas. Уже настроено для JetBrains Mono (входит в папку `fonts\`, лицензия SIL Open Font License).

### `[sticky]` — второй, курируемый список

**`default_category`** (по умолчанию "Unsortiert") — используется, когда вы перетаскиваете прямо на сам `! StickySnips`, а не в категорию.

### `[textbaustein]` — объединение фрагментов

Новая структура: добавление работает теперь только внутри `! Textbaustein\Entwurf\` — сам корень `! Textbaustein` "зафиксирован", туда больше ничего не добавляется автоматически. Закончив сбор, переименуйте через **F6** из `Entwurf\` наружу (например, `Entwurf\y` → `config-final`) — смена папки и присвоение окончательного имени происходят за один шаг, через собственный диалог переименования TC.

**`separator_blank_lines`** (по умолчанию 1) — сколько пустых строк между добавленными частями.

**`highlight_last_append`** (по умолчанию 1) — открытие Textbaustein через F3 автоматически выделяет последний добавленный фрагмент (обычное выделение текста Windows, исчезает при первом клике).

**Комментарии**: StickySnips и Textbaustein могут нести короткую заметку для узнавания (удобно для коротких имён вроде "y" или "z"). Alt+Enter показывает комментарий, кнопка "редактировать" внизу слева открывает отдельную небольшую маску с **Ctrl+E**/**Ctrl+S** — тот же принцип, что и в Lister. `! Kommentare` показывает все установленные комментарии одним списком. Подробности и почему это отдельное решение, а не DescriptEdit напрямую: см. [заметку о комментариях](notes/comments/comments.ru.html).

### `[path_resolve]` — пути к файлам вместо текста

По умолчанию выключено. При включении SnipClip преобразует копии файлов в текст:

| Формат | Пример |
|---|---|
| `local` | `C:\Users\Name\File.txt` |
| `forwardslash` | `C:/Users/Name/File.txt` |
| `unc` | `\\server\share\File.txt` |
| `fileuri` | `file:///C:/Users/Name/File.txt` |
| `wsl` | `/mnt/c/Users/Name/File.txt` |

`AllowExtensions`/`AllowFolders` ограничивают это через список, разделённый точкой с запятой.

### `[Settings]` — прочее

- **`RespectClipboardExclude`** (по умолчанию 1) — уважать сигнал менеджера паролей
- **`StartPaused`** (по умолчанию 0) — ClipWatch запускается активным или намеренно неактивным
- **`LiveRefreshAfterCapture`** (по умолчанию 1) — панель обновляется автоматически после нового захвата

### Дополнительные столбцы
Пять дополнительных столбцов через настройку столбцов TC: **Edited**, **Diff**, **Source**, **Age**, **Verknuepft** (заполняется только для скриншотов, показывает имя связанной заметки).

## Архитектура вкратце

Две отдельные библиотеки DLL в одном процессе TC: `SnipClip.wfx`/`.wfx64` (панель, история, StickySnips, Textbaustein, ClipWatch) и `SnipClipLister.wlx`/`.wlx64` (только редактор Ctrl+E). Почему оба используют префикс `TC_SnipClip_` для окон/сообщений: см. [заметку об именовании оконных классов](notes/window-class-naming/window-class-naming.ru.html).

## Установка

**WFX:** Конфигурация → Настройки → Плагины → Плагины файловой системы → Настроить → Добавить, выбрать `SnipClip.wfx64`.

**WLX:** Конфигурация → Настройки → Плагины → Lister-плагины → Настроить → Добавить, выбрать `SnipClipLister.wlx64`, затем вручную привязать к расширению `snip`.

**Рекомендуется:** установить `AutoReUpload=2` в `wincmd.ini` — см. [заметку об AutoReUpload](notes/autoreupload/autoreupload.ru.html).

## Сборка

MinGW-w64 (64-бит в `C:\mingw64`, опционально 32-бит в `C:\mingw64\mingw32`). Запустить `build_debug.bat`, бинарные файлы попадут в `release\`.
