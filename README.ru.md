# SnipClip

Плагин для Total Commander, превращающий буфер обмена в доступный для поиска, постоянный каталог. Не отдельная программа, без значка в трее, без собственного постоянно открытого окна — SnipClip полностью живёт внутри TC, как виртуальная панель под `\SnipClip`.

## Что умеет

Вы копируете как обычно — Ctrl+C, из любой программы. SnipClip перехватывает это в фоне (ClipWatch, невидимое окно, зарегистрированное в Windows для отслеживания изменений буфера обмена, без опроса) и помещает текст в панель `\SnipClip` как виртуальный файл.

**Пароли остаются в стороне.** Когда приложение намеренно копирует что-то, что не должно отслеживаться — Bitwarden, KeePassXC, 1Password, режим инкогнито Chrome — оно помечает это официальным сигналом Windows. SnipClip уважает это и оставляет такие копии полностью нетронутыми. Честная оговорка: это добровольная просьба, а не принудительная блокировка — некоторые источники просто не устанавливают этот сигнал. Тот, кто всё же хочет перехватывать всё для собственного тестирования, может отключить это.

**История в принципе неизменяема** — но теперь не совсем без выхода. Изначально только `! Verlauf leeren` (очистить всё сразу) могло что-то удалить. Теперь, если туда попало что-то неправильное, можно удалить и отдельную запись — под защитой собственного дополнительного подтверждения поверх обычного запроса TC на удаление. Кто предпочитает прежнее строгое правило, может снова его включить.

**Редактирование возможно, но не оригинала.** F3 открывает сниппет в собственном Lister-плагине SnipClip. Ctrl+E переключает в режим редактирования (фон становится светлым), вы исправляете, Ctrl+S записывает прямо обратно в буфер обмена. Сама строка истории остаётся неизменной, вы лишь видите отметку о том, было ли и насколько сильно последнее редактирование.

**Важное вы закрепляете.** F5 или перетаскивание в категорию под `! StickySnips` — категории создаются через F7. Закреплённые сниппеты сохраняются, даже когда остальная история давно уже вытеснена.

**Объединение нескольких фрагментов в одно целое** перед использованием — фрагменты кода или текста, которые вы копируете один за другим под одним и тем же введённым именем в `! Textbaustein`, там добавляются, а не заменяются. Подробности о том, почему это работает только по одному: см. [заметку о Textbaustein](notes/textbaustein/textbaustein.ru.md).

**Если вы копируете файл вместо текста**, SnipClip по умолчанию это игнорирует. Включив разрешение путей, вы получите путь к файлу в виде текста, собранного под `! Pfade`, полностью отдельно от основной истории.

**Новые сниппеты появляются сразу**, без ручного Ctrl+R — как только вы хоть раз взаимодействовали с панелью (например, Alt+Enter), вид автоматически обновляется после каждого нового захвата.

Alt+Enter на отдельной записи показывает источник, категорию (для закреплённых сниппетов), время (абсолютное и относительное), статус редактирования и полное содержимое. Alt+Enter на одной из специальных строк показывает вместо этого общий обзор — время работы, статистику сессии, рейтинг источников, количество StickySnips, статистику редактирования, реальное использование диска.

## Подробности

### Структура панели: `! menu`

Все командные строки (`! ClipWatch pausieren`, `! Verlauf leeren`, `! StickySnips`, `! Pfade`, `! Textbaustein`) по умолчанию собраны под одной строкой: `! menu`. Это делает корень аккуратным — только ваши реальные сниппеты видны сразу.

```ini
[menu]
RootButtons=
```

Если вы предпочитаете, чтобы определённые команды были прямо в корне (например, потому что вы часто заходите в StickySnips), укажите их ключи через запятую: `RootButtons=Sticky,Path`. Доступные ключи: `Pause`, `Clear`, `Sticky`, `Path`, `Textbaustein`.

### `[history]` — основные настройки истории

- **`max_entries`** (по умолчанию 100) — максимум записей одновременно, самая старая автоматически удаляется
- **`name_preview_length`** (по умолчанию 20) — символы для имени в панели
- **`persist_history`** (по умолчанию 1) — сохраняется ли после перезапуска TC
- **`dedup_consecutive`** (по умолчанию 1) — две одинаковые копии подряд создают только одну запись
- **`AllowSingleDelete`** (по умолчанию 1) — можно ли вообще удалять отдельные записи

### `[Theme]` — внешний вид

Собственная тема "Basic" ("Alien Blood") как отличительная черта — почему у каждого нашего плагина своя: см. [заметку о теме Basic](notes/basic-theme/basic-theme.ru.md). Для согласованности с другими плагинами: `Name=gruvbox|everforest|solarized`, каждая с `Mode=dark|light`. `NoColors=1` в `[Settings]` полностью отключает любую тему.

**`FontBrightness=`/`BackgroundBrightness=`** (от -3 до +3, по умолчанию 0) — тонкая настройка яркости через фиксированные, проверенные шаги. Если комбинация даёт слишком низкий контраст, автоматически применяется безопасное значение с предупреждением в окне Alt+Enter.

### `[lister]` — редактор

Намеренно использует другую тему, чем остальной плагин (тёмная для чтения, светлая для редактирования): `gruvbox`, `everforest` или `solarized`. Почему сохранение здесь работает без ошибки загрузки TC: см. [заметку об AutoReUpload](notes/autoreupload/autoreupload.ru.md).

**`MonoFont=`/`MonoFontName=`** — собственный моноширинный шрифт вместо Consolas. Уже настроено для JetBrains Mono (входит в папку `fonts\`, лицензия SIL Open Font License).

### `[sticky]` — второй, курируемый список

**`default_category`** (по умолчанию "Unsortiert") — используется, когда вы перетаскиваете прямо на сам `! StickySnips`, а не в категорию.

### `[textbaustein]` — объединение фрагментов

**`separator_blank_lines`** (по умолчанию 1) — сколько пустых строк между добавленными частями. Подробности: [заметка о Textbaustein](notes/textbaustein/textbaustein.ru.md).

### `[path_resolve]` — пути к файлам вместо текста

По умолчанию выключено. При включении SnipClip преобразует копии файлов в текст:

| Формат | Пример |
|---|---|
| `local` | `C:\Users\Name\File.txt` |
| `forwardslash` | `C:/Users/Name/File.txt` |
| `unc` | `\\server\share\File.txt` |
| `fileuri` | `file:///C:/Users/Name/File.txt` |
| `wsl` | `/mnt/c/Users/Name/File.txt` |

`AllowExtensions`/`AllowFolders` ограничивают это через список, разделённый точкой с запятой.

### `[Settings]` — прочее

- **`RespectClipboardExclude`** (по умолчанию 1) — уважать сигнал менеджера паролей
- **`StartPaused`** (по умолчанию 0) — ClipWatch запускается активным или намеренно неактивным
- **`LiveRefreshAfterCapture`** (по умолчанию 1) — панель обновляется автоматически после нового захвата

### Дополнительные столбцы
Четыре дополнительных столбца через настройку столбцов TC: **Edited**, **Diff**, **Source**, **Age**.

## Архитектура вкратце

Две отдельные библиотеки DLL в одном процессе TC: `SnipClip.wfx`/`.wfx64` (панель, история, StickySnips, Textbaustein, ClipWatch) и `SnipClipLister.wlx`/`.wlx64` (только редактор Ctrl+E). Почему оба используют префикс `TC_SnipClip_` для окон/сообщений: см. [заметку об именовании оконных классов](notes/window-class-naming/window-class-naming.ru.md).

## Установка

**WFX:** Конфигурация → Настройки → Плагины → Плагины файловой системы → Настроить → Добавить, выбрать `SnipClip.wfx64`.

**WLX:** Конфигурация → Настройки → Плагины → Lister-плагины → Настроить → Добавить, выбрать `SnipClipLister.wlx64`, затем вручную привязать к расширению `snip`.

**Рекомендуется:** установить `AutoReUpload=2` в `wincmd.ini` — см. [заметку об AutoReUpload](notes/autoreupload/autoreupload.ru.md).

## Сборка

MinGW-w64 (64-бит в `C:\mingw64`, опционально 32-бит в `C:\mingw64\mingw32`). Запустить `build_debug.bat`, бинарные файлы попадут в `release\`.
